# Колобок — Побег из избы

Колобок сбежал из избы и падает всё глубже: прыгай по полкам, собирай изюм, уворачивайся от ос, мышей и кота, а сверху катится скалка.

**Играть в браузере:** https://maximlabin.github.io/kolobok/

Управление: веди пальцем (или мышью) влево-вправо, прыжок — тап, свайп вверх или стрелка вверх. На компьютере — стрелки.

Сделано на Godot 4.7.
